**Sign rule (display layer, all screens):** negative = loss/short, **red**, with a true minus `−` (U+2212), never a hyphen. Positive = excess, **amber**, with `+`. Zero = **green**, "Matched".

Each state carries an **icon and a word** ("Short", "Excess", "Matched") next to the value so it reads without colour. Percent goes right after the litres: `−42 L (−0.52%)`.

**Stock variance is shown as Nozzle L − Tank L** so a leak is negative like cash. The PRD engine formula (Tank − Nozzle) is flipped only in the UI. Money: `−₹1,250`; litres: `−42 L` (up to 2 decimals).
