**Toast:** inverse surface (`text-primary` on `bg`), icon + one short sentence, dismiss X, `shadow-sheet`, 4s auto-hide; error toast is solid `danger` and stays until dismissed and carries the retry.

**Empty state:** one icon, ONE line, ONE action. No illustration. Copy: "No credit sales yet today" + "Add credit sale".

**Skeleton:** `auto-field-bg` to `border` shimmer, matching the real card/list geometry; stops with reduced motion.
