One **primary L** per screen, docked in the sticky bar. **M** is for actions inside cards, banners and lists (pad the hit area to 48px).

- **primary:** solid `primary`, text `on-primary`. **secondary:** 1.5px `primary` outline. **ghost:** text only. **destructive:** solid `danger`, used only for Unlock day / Delete.
- **Loading:** keep the label ("Saving…"), show a spinner, block taps. **Disabled:** `auto-field-bg` fill, `text-muted` text; always show why nearby ("Finish 3 sections to submit").
- Labels are verbs: "Save & next section", "Add reason", "Lock day".
