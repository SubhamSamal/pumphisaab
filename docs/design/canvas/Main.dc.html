Design principles applied
Version 2. Twelve rules from form-design research, Indian small-business apps, audit-trail practice and your feedback. Each one points to the flows below where you can see it in use. Sample data throughout: Shree Lokanath Filling Station, 01 Oct 2026, HSD ₹90.00, MS ₹101.00.
01

One column, big numbers, unit inside the box

Short label above, number in 24px, unit (₹, L, cm) inside the box. Only the boxes that change are boxes.

02

Right keypad, Next moves on

Every number opens the number pad. Next walks from one closing reading to the next, and one shift box to the next.

03

Fill in anything already known

Opening = last closing, price = the owner's price, tanker price and margin = last tanker. Worked-out numbers are grey with a lock.

No mental maths

04

Stop impossible numbers at the box

Chips and toggles for short choices. Red only for numbers that can't be true (closing below opening, dip beyond the tank, same slip twice).

05

Check when the box is left, not while typing

An error appears under the box once you move on, in one plain sentence that suggests the fix.

06

Flag, don't question

Anything outside the limit becomes an amber flag that goes to the owner. The manager is never asked for a reason; the owner calls if needed.

07

Make the day feel short

One price tap, 8 sections, grey "to do" circles, a progress bar, visible autosave, and a Submit button that says what's left.

08

History: who, what, old to new, when

An amber "Changed" tag and history button on the number itself. The history can't be edited by anyone.

Outdoor, one hand, budget Android

Key numbers at 7:1 contrast, 16px minimum, 48px taps, main button at the bottom in thumb reach, alerts behind one bell.

10

Pump words, not accountant words

Like Khatabook: one job per screen and the words people already say. Opening, closing, short, excess, should have, received.

Colour is never the only signal

Every difference has a sign, an icon and a word: Short −₹1,250, Excess +₹300, Matched. Calendar cells add an icon.
